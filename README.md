В рамках проекта была решена задача бинарной классификации на датасете Iris с использованием логистической регрессии. Исходный датасет был преобразован в бинарную постановку задачи путем удаления одного класса и перекодировки оставшихся классов в значения -1 и 1.
Обученная модель показала хорошее качество классификации: точность на тестовой выборке составила примерно 0.90–0.95 в зависимости от разбиения данных. Это указывает на то, что выбранная модель адекватно описывает структуру данных.
Анализ матрицы ошибок и метрик classification report показывает, что модель в целом корректно разделяет классы, а ошибки в основном возникают в области их пересечения, что ожидаемо для линейной модели на подобных данных.
Дополнительно можно отметить, что логистическая регрессия является хорошим базовым (baseline) методом для данной задачи и может использоваться для сравнения с более сложными алгоритмами.
